# Retired generation experiment

Earlier traversal sheets were generated with imagegen using reference contact sheets as proportion/style input. They were experimental key poses, not verified full animation cycles. The current release replaces all character art with the CC0 set documented in [the character catalogue](../character/README.md).

No PNG from this experiment is loaded or distributed in the current tree. The earlier prompts and process remain in [the generation record](../../Documents/Plans/Design/generated-character-actions.md) as development history; the images are kept in the private workspace archive. No new generation was needed for the open-art replacement.
