# Vector action-image reference catalogue

Collected and visually reviewed: **22 October 2026**. Source: the publisher's [official Steam gallery](https://store.steampowered.com/app/248970/Vector/), associated with the [requested Vector reference](https://vector.game/zh-Hans/). Steam edition/browser-build parity is unverified.

The author later clarified that the intended material is character animation frames. This promotional collection is supplemental. See [original-data character-frame extraction](vector-character-frames.md) for the separate completed frame archive.

## Stored collection

17 original JPEG images: **10 gameplay stills, 3 trick-card screens and 4 level/menu context screens**. Every image was opened and classified from visible content. Source bytes are preserved without crops, upscaling or watermark removal. The source filename's resolution suffix does not guarantee actual dimensions; measured dimensions are recorded.

Image files are stored outside the repository at workspace `.midwork/assignment3/reference-assets/vector/`. Open its `gallery.html` for a filterable local contact gallery. Each image has one primary category and secondary manifest tags; no redundant image copies are created for multiple actions.

The canonical metadata is [asset-manifest.json](VectorAssets/asset-manifest.json), including source URL/page, original filename, date, dimensions, byte length, SHA-256, observed labels, interpretation limits and rights status. The local archive and Chinese tree contain identical read-only metadata copies. English/Chinese prose is not a second source of image identity.

## Interpretation and reuse boundaries

- VEC-001/002 show named airborne tricks; VEC-011/013/014 show named silhouette cards. Labels describe visible reference UI, not measured animation cycles or our final feature list. VEC-014's unusual label spelling is preserved in metadata.
- Wall/ledge stills do not establish an exact climb/hang/fall transition. A grounded pose is not automatically a slide or landing. Use each record's uncertainty note.
- This promotional collection itself contains no isolated slide sequence or complete animation cycle; the separate character-frame archive now provides source pose sequences, including slides. No image verifies dash grapple, swing grapple, zipline or jump pad as Vector mechanics; those are our additions. Do not fill evidence gaps with fabricated or AI-generated "reference" images.
- Images remain publisher-owned promotional material. No reusable runtime-asset licence was identified. The archive is for local visual research and is excluded from the Git repository, game bundle and Pages output; source attribution does not itself grant runtime redistribution rights.
- No login, purchase, game-bundle extraction, gameplay start or agreement acceptance was needed. The Steam API metadata request failed; acquisition succeeded through the public page's gallery and supported browser asset export.

The project creates original visual assets. Connect these references to [3C](../Design/three-c-design.md), [state-machine design](../Design/character-state-machine.md) and [scene recipes](../Design/parkour-scene-implementation.md), without treating promotional pixels as an executable gameplay specification.
