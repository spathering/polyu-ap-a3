    Workspace guide

    Build → adjust → play

    1. Drag a small module from the library onto the scene. Its entry pivot follows the cursor.
    2. Use B to draw terrain blocks; H is the character climb limit. V selects, Shift or box drag selects a group. Snap is on by default. The grid offers H, H/2 and H/4; turn Snap off for free placement.
    3. Double-click a unit to edit its shared geometry and detectors. All its instances update together; make it unique first for a variant.
    4. Use Quick test, then return to the unchanged draft. Export the full validated content package when ready.
